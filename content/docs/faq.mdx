# <T translationKey="docs.faq.title">Frequently Asked Questions</T>

## <T translationKey="docs.faq.q1.question">Is the script safe?</T>

<T translationKey="docs.faq.q1.answer">
  The script only runs benchmark tests on your machine. It doesn't install
  software or modify system configuration. You can view the source code on
  GitHub before running.
</T>

## <T translationKey="docs.faq.q2.question">Is my data secure?</T>

<T translationKey="docs.faq.q2.answer">
  You can choose 'local' mode to not send data to server. Or choose 'private' so
  only people with URL can view. Only when choosing 'shared' will results be
  displayed publicly.
</T>

## <T translationKey="docs.faq.q3.question">Does the script require root?</T>

<T translationKey="docs.faq.q3.answer">
  No, the script doesn't require root. However, some tests may need certain
  permissions (e.g., ping test).
</T>
